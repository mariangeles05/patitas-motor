# patitas-motor


Minimal linked-node model for Patitas' clinical history.

## Structure

- `src/Nodo.js`: `Nodo` class (`dato`, `siguiente`).
- `pruebas/nodos.js`: links 3 visits of Lola (cat, 4 years old) and traverses them with `while`.
- `bitacora.md`: diagram and lost-link explanation.

## Run

    node pruebas/nodos.js

Expected output: the 3 visits in order and a total of $275.000.
